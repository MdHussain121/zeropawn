# Security Policy

## Supported Versions

Security updates and bug fixes are applied to the latest development branch.

| Branch / Release | Supported |
|---|---|
| `main` / `master` | :white_check_mark: |
| Historical branches | :x: |

---

## Reporting a Vulnerability

We take security and safe code execution seriously.

If you believe you have found a security vulnerability in ZeroPawn (e.g., path traversal, unverified binary execution, unsafe deserialization, or credential leakage), please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately via **GitHub Security Advisories** (found under the "Security" tab of the repository).
3. If private advisories are unavailable, contact the project maintainers directly via their listed maintainer contact.

### What to Include in Your Report:
- Detailed description of the potential vulnerability.
- Steps or a minimal proof-of-concept demonstrating the issue.
- Potential impact and affected platforms (Windows, Linux, macOS).
- Any proposed mitigations or patch suggestions.

We will acknowledge receipt within 48 hours and coordinate a fix and advisory.
